# v1 API 请求速率

API：v1 和 v4 速率限制（按小时）： 注：批量抓取 1 次最多 50 条

## 用量规则

| 套餐版本   | 请求速率  |
|--------|-------|
| 免费版    | 100   |
| 专业版    | 1000  |
| 专业增强版  | 1000  |
| 团队版    | 1000  |
| 企业基础版  | 20000 |
| 企业协作版  | 30000 |
| 企业高级版  | 50000 |
| 商业合作版  | 50000 |

> 速率按 Token 计算。超出限制时接口返回 `429`，响应中会带上当前套餐、剩余次数和恢复时间。
